# Hardware type

The USB2CANFDV1 has three LEDs.

| Label  | Color | Description                |
|--------|-------|----------------------------|
| RDY    | Red   | Power, Upgrade/Normal mode |
| RX     | Green | Data reception             |
| TX     | Blue  | Data transmission          |


# LED behavior
The rules are applied from top.

### Upgrade mode

* RDY: Blink

### Startup

* RDY: Constant ON
* RX & TX: Blink 5 times in total

### Error stored

* RDY: Constant ON
* RX & TX: Constant ON

### CAN bus closed

* RDY: Constant ON
* RX: Blink by a command reception
* TX: Constant ON

### CAN bus open

* RDY: Constant ON
* RX: Blink by a CAN frame reception
* TX: Blink by a CAN frame transmission

# Option bytes

At boot, the firmware sets the brown-out reset (BOR) level in the option bytes to level 4, if it is not set yet.
At this level, the MCU stays in reset until the supply voltage rises above about 2.9 V (the falling threshold is about 2.8 V).
This avoids entering the bootloader by mistake when a USB hub ramps up the supply slowly.

- The setting takes effect on the next power cycle, not on a reset.
- It is stored in the device and remains after another firmware is flashed.
- No other option bytes are changed, including the BOOT0-related bits, so the BOOT0 jumper keeps working to enter the bootloader.
